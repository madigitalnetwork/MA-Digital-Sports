Free cricket APIs only return the running total, not a record of each delivery. So the server compares two consecutive updates — if the score went up by four and the ball count went up by one, that was a boundary. If you need exact ball-by-ball data, subscribe to a paid feed (CricAPI's ball-by-ball plan, EntitySport, and similar) and change one function in the server.
